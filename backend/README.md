# Physics Atlas API

This package contains the read-oriented FastAPI service, PostgreSQL models,
incremental scientific-source connectors, update worker, and resource monitor
for Physics Atlas v3.0.4-alpha.

The service is deployment-ready infrastructure. It is not a claim that a
public live backend is currently hosted, and its deterministic fixture mode is
the default for local development and automated tests.

See [`../docs/backend.md`](../docs/backend.md) for setup and operational
guidance.
