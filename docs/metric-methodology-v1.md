# Candidate Metric Methodology v1 — Historical Note

Status: **superseded candidate record; not a production metric contract**.

This path is retained so links from the v3.0.5-alpha development record do not
break. The earlier candidate explored publication counts, citation
percentiles, distinct-partner counts, Shannon evenness, and symmetric temporal
change. It was never activated on the live Atlas.

The implemented Atlas Physicus Metric System v1 replaces those provisional
choices with one coherent, exact-five framework built on paper-time fractional
attribution:

- field-weighted fractional publication Activity;
- fractional MNCS with PP(top 10%) companion Impact evidence;
- entity-appropriate collaboration proportions with graph companion evidence;
- normalized Shannon-evenness Diversity;
- backward-looking, field-relative rolling-window Momentum.
