## Robustness checks

- Missing inputs remain absent; no missing value is written or displayed as
  zero.
- The candidate Activity and Connectivity transforms use `log1p` and stored
  robust cohort quantiles so one outlier cannot determine the full scale.
- Impact excludes papers younger than 24 months and compares only within a
  field/publication-year cohort, preventing very recent raw counts from being
  treated as mature impact.
- Every metric minimum includes relationship/coverage requirements, preventing
  sparse institutions from receiving falsely precise scores.
- No live metric layer is activated by this snapshot.
